# Siddhesh Bhande: Personal Software Engineering Portfolio

A responsive web application showcasing full-stack software engineering projects, interactive geospatial visualizations, performance metrics, and technical case studies.

## Key Features

- **Interactive Spatial Visualizations**: Dynamic mapping layers and choropleth maps built with Leaflet.
- **Performance & Analytics Dashboards**: Interactive metrics and time-series charts powered by Chart.js.
- **Fluid Motion Design**: Seamless transitions, smooth card reveals, and route changes orchestrated with Framer Motion.
- **Responsive Layout**: Utility-first CSS styling designed with Tailwind CSS.

## Technology Stack

- **Framework**: React 18
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Visuals & Charts**: Leaflet, Chart.js, React-Chartjs-2
- **Animation**: Framer Motion
- **Icons**: React Icons

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Siddhesh-Bhande/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm start
   ```

4. Build for production:
   ```bash
   npm run build
   ```
